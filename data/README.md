# Data

These folders represent different data inputs:
- Processed GLS location: `positionsIRMA`
- Activity data: `wetdry_raw` - adult activity data which have corresponding GLS locations
- Environmental variables: `ice`, `sst` and `temp` (air temperature)
- Merge GLS, activity and environmental information: `birddata_ind` - one file for each bird contained within six folders corresponding to different species (`northernfulmar`, `atlanticpuffin`, `littleauk`, `blackleggedkittiwake`, `commonguillemot`, `brunnichsguillemot`)
